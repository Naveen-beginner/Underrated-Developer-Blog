# The Underrated Developers

A website built to share our thoughts and ideas in and about Android Application Developement

```bash
For Developers, By Developers - Underrated Devs
```


## Topics Covered
- Dart
- Flutter
- App - From Idea To Production
- Connect Flutter to Node/Express/Mongo Backend
- Getting your app live on Google Play store
And many more..

## Prerequisites
- Beginner Level Experience with Dart and Flutter
- Experience building apps with Flutter
- Experience with IDEs like Android Studio or VS Code
```
Note: Knowledge of using Dart and Flutter commands in terminal is a must
```
